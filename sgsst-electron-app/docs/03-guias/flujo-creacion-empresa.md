# Flujo de Creación de Empresa

## Proceso General

El flujo de creación de empresa permite registrar una nueva empresa en el sistema SG-SST y asignarle el escenario normativo correspondiente.

## Pasos del Proceso

### 1. Registro de Información Básica
- Nombre de la empresa
- NIT
- Dirección
- Teléfono
- Correo electrónico
- Número de trabajadores
- Actividad económica (CIIU)
- Nivel de riesgo

### 2. Determinación del Escenario Normativo
El sistema determina automáticamente el escenario normativo basado en:
- Tamaño de la empresa
- Nivel de riesgo
- Actividad económica

### 3. Activación de Módulos
Según el escenario normativo:
- Se activan los módulos obligatorios
- Se desactivan los módulos no aplicables
- Se configuran los requisitos específicos

### 4. Asignación de Responsables
- Se asignan responsables para cada módulo
- Se configuran permisos de acceso
- Se establecen notificaciones

## Validaciones

Durante el proceso se realizan las siguientes validaciones:
- Formato correcto de NIT
- Número de trabajadores válido
- Nivel de riesgo coherente con la actividad
- Información completa

## Resultado

Al finalizar el proceso:
- La empresa queda registrada en el sistema
- Los módulos correspondientes están activos
- Se puede comenzar a gestionar los requisitos normativos
