# v0.1.95 - Widgets COPASST, Convivencia, Afiliación e Inducciones: Progreso Anual y Último Registro con Año

**Fecha:** 27 de Marzo 2026
**Tipo:** Mejora de UX + Visualización de Datos
**Impacto:** Recursos Home, Backend (main.js)

---

## 📋 Resumen

Esta actualización introduce:
1. **Widget COPASST muestra progreso anual** (X / 12 reuniones)
2. **Widget Comité de Convivencia muestra progreso anual** (X / 12 reuniones)
3. **Widget Afiliación SSSI muestra progreso anual** (X / 12 planillas)
4. **Widget Inducciones muestra progreso** (X / Y trabajadores con inducción)
5. **"Último registro" ahora incluye año** (ej: "dic 2024" en lugar de solo "diciembre")
6. **Barra de progreso visual** para todos los widgets
7. **Formato consistente "X / Y"** en todos los widgets

---

## 🎯 Objetivos

### 1. Progreso Anual en Widgets (X / 12)

**Problema anterior:**
```
┌─────────────────────────────────────┐
│  Actas COPASST 2026    [Pendiente] │
│                                     │
│         45 actas                    │  ← TOTAL HISTÓRICO (todos los años)
│                                     │
│  Mes actual    │  Último registro  │
│  marzo         │  diciembre        │  ← ¿De qué año?
└─────────────────────────────────────┘
```

**Nueva implementación:**
```
┌─────────────────────────────────────┐
│  Actas COPASST 2026    [Pendiente] │
│                                     │
│         3 / 12                      │  ← Solo año actual (formato consistente)
│         [████████░░░░░░] 25%        │  ← Barra de progreso
│                                     │
│  Mes actual    │  Último registro  │
│  marzo         │  dic 2024         │  ← Mes + año
└─────────────────────────────────────┘
```

**Cambios:**
- ✅ Muestra actas del **año en curso** (no total histórico)
- ✅ Formato "X / 12" indica reuniones realizadas vs esperadas (consistente con inducciones)
- ✅ Barra de progreso visual animada (0-100%)
- ✅ "Último registro" incluye año para claridad

### 2. "Último registro" con Año

#### Problema Detectado

**Antes (v0.1.94):**
```javascript
// Solo comparaba índice de mes (0-11), ignorando el año
let ultimoMesIndex = -1;

if (monthIndex > ultimoMesIndex) {
  stats.ultimoMesRegistrado = mesEncontrado; // "diciembre"
  ultimoMesIndex = monthIndex;
}
```

**Resultado confuso:**
- Si existía un acta de **diciembre 2024**
- Y estás en **marzo 2026**
- Mostraba: `"diciembre"` ❌ (¿de qué año?)

#### Solución Implementada

**Ahora (v0.1.95):**
```javascript
// Compara fecha completa (año + mes)
let ultimaFechaRegistro = null; // { date: Date, display: "dic 2024" }

const fechaActa = new Date(folderYear, monthIndex);
if (!ultimaFechaRegistro || fechaActa > ultimaFechaRegistro.date) {
  const mesCorto = mesEncontrado.substring(0, 3); // "dic", "feb", etc.
  stats.ultimoMesRegistrado = `${mesCorto} ${folderYear}`;
  ultimaFechaRegistro = { date: fechaActa, display: stats.ultimoMesRegistrado };
}
```

**Resultado claro:**
- Si última acta es de **diciembre 2024**
- Muestra: `"dic 2024"` ✅ (claro y preciso)

**Ahora:**
```javascript
const stats = {
  totalTrabajadores: 0,
  totalInducciones: 0,
  completadas: 0,
  pendientes: 0,
  porcentajeCompletado: 0,
  mensual: new Array(12).fill(0),
  ultimoMesRegistrado: null  // ← NUEVO
};

// Track del último mes registrado
let ultimoMesRegistrado = null;

// Dentro del loop:
if ((rowDate && rowDate.getFullYear() === currentYear) || yearVal === currentYear) {
    stats.totalInducciones++;
    stats.completadas++;
    if (rowDate) stats.mensual[rowDate.getMonth()]++;

    // Track del último mes encontrado (considerando año + mes)
    if (rowDate) {
        const monthIndex = rowDate.getMonth();
        const fileYear = rowDate.getFullYear();
        const fechaInduccion = new Date(fileYear, monthIndex);
        
        if (!ultimoMesRegistrado || fechaInduccion > ultimoMesRegistrado.date) {
            const mesCorto = rowDate.toLocaleString('es-ES', { month: 'short' });
            ultimoMesRegistrado = {
                date: fechaInduccion,
                display: `${mesCorto} ${fileYear}`
            };

    }
}
```

### Cálculo de Porcentaje

```javascript
// Fórmula
porcentajeProgreso = Math.min((actasAnio / 12) * 100, 100);

// Ejemplos:
0 / 12  = 0%    → barra vacía
3 / 12  = 25%   → 1/4 de la barra
6 / 12  = 50%   → mitad de la barra
9 / 12  = 75%   → 3/4 de la barra
12 / 12 = 100%  → barra llena
> 12    = 100%  → capped en 100%
```
