# v0.1.98 - Actas COPASST: Autollenado Mejorado (Plan Mes Anterior + Accidentalidad Enriquecida)

**Fecha:** 4 de junio de 2026
**Tipo:** Corrección de Errores + Mejora Funcional
**Impacto:** Módulo Recursos, Submódulo 1.1.6 Conformación de Copasst, Backend (IPC `get-copasst-auto-fill-data`)

---

## Resumen

Esta actualización corrige y mejora el autollenado de actas COPASST en 4 areas:

1. **Plan de Trabajo lee mes anterior** (norma COPASST: acta revisa actividades del mes previo)
2. **Texto formateado con `\n`** en desarrollo items (numeracion, agrupacion por estado)
3. **Fix bug de mes en nombre de archivo** al guardar acta
4. **Accidentalidad enriquecida** con identificacion y fecha del accidente

---

## Cambios Detallados

### 1. Plan de Trabajo: Columna del Mes Anterior

**Antes:** El autollenado leia la columna del mes objetivo (`targetMonthKey`) del Plan de Trabajo, mostrando actividades del mes de la reunion.

**Despues:** Lee la columna del **mes anterior** (`previousMonthKey`), que es lo correcto segun la norma COPASST — el acta revisa lo ejecutado en el mes previo.

**Cambio principal (main.js ~9105):**

```javascript
// ANTES
const colLetter = targetMonthKey; // e.g. 'F' para Marzo

// DESPUES
const colLetter = previousMonthKey; // e.g. 'E' para Febrero (si acta es de Marzo)
```

**Transicion de ano (Enero → Diciembre anterior):**

```javascript
// Busca el Plan del ano anterior si el mes anterior es Diciembre
const planYearForPrevious = previousMonthKey === 'O' // Diciembre
  ? previousMonthYear   // e.g. 2025
  : targetYear;         // e.g. 2026
```

Logica: si el acta es de Enero 2026, el mes anterior es Diciembre 2025, y busca en `Plan de Trabajo 2025.xlsx` (no en 2026).

### 2. Texto Formateado en Desarrollo Items

**Antes:**
> Plan de Trabajo: 1. Actividad A - Programado, 2. Actividad B - Completado

**Despues:**
```
Plan de Trabajo del mes de Febrero 2026:
 1. Actividad A — ⏱ Programado
 2. Actividad B — ✓ Completado
 3. Actividad C — ⏱ Programado
```

Cambios aplicados:
- Salto de linea (`\n`) entre titulo y actividades
- Numeracion con punto
- Separador `—` entre nombre y estado
- Iconos ✓ (Completado) y ⏱ (Programado)
- Agrupacion por estado: Completados primero, luego Programados
- Referencia al **mes anterior** en el texto (`previousMonthName`)

**Auto-calculo de filas en textarea (copasst-logic.js ~503, ~608):**

```javascript
// ANTES
temaRows: 2  // fijo

// DESPUES
temaRows: Math.max(2, (tema.match(/\n/g) || []).length + 1)  // dinamico segun \n
```

### 3. Fix: Bug de Mes en Nombre de Archivo al Guardar

**Antes:** `new Date(data.fecha).getMonth()` podia devolver mes incorrecto por el bug UTC de JavaScript (Colombia UTC-5).

**Despues:** `parseInt(data.fecha.split('-')[1], 10) - 1` — parseo directo del string `YYYY-MM-DD`.

**Fix en copasst-logic.js ~658:**

```javascript
// ANTES
const mes = monthNames[new Date(data.fecha).getMonth()];

// DESPUES
const mesIdx = parseInt(data.fecha.split('-')[1], 10) - 1;
const mes = monthNames[mesIdx];
```

### 4. Fix: "N°" Eliminado del Nombre de Archivo

**Antes:** `Acta Copasst N°5 Junio 2026.xlsx`
**Despues:** `Acta Copasst Junio 2026.xlsx`

### 5. Accidentalidad Enriquecida

**Antes:**
> En el mes de Diciembre 2025, Se presento(ro) 1 accidente(s) de trabajo de: Lilibeth.

**Despues:**
```
En el mes de Diciembre 2025, Se presento(ro) 1 accidente(s) de trabajo:
 1. Lilibeth Perez — CC 22510033 — 15/12/2025
```

**Columnas leidas del Excel de accidentalidad:**

| `Nombre Completo` | Nombre del trabajador | `Nombre` → `Trabajador` |
| `Identificacion` | Numero de cedula | `Cedula` |

| Campo | Tipo | Descripcion |
|-------|------|-------------|
| `identificacion` | `string \| null` | Cedula del trabajador |

## Lecciones Aprendidas

1. **Bug UTC de `new Date()`:** En zona UTC-5 (Colombia), `new Date('2026-06-15')` puede interpretar como 14 de junio a medianoche UTC. Siempre parsear strings `YYYY-MM-DD` con `.split('-')` en lugar de `new Date()`.
2. **Norma COPASST:** Las actas revisan actividades del mes **anterior**, no del mes de la reunion. El Plan de Trabajo siempre debe leer la columna del mes previo.
3. **Texto multilinea en Excel:** openpyxl preserva `\n` en celdas — no se necesita conversion especial para export.
4. **Fallback de columnas:** Los archivos Excel de accidentalidad pueden tener diferentes nombres de columnas segun la empresa. La cadena de fallback (`Nombre Completo` → `Nombre` → `Trabajador`) cubre las variaciones mas comunes.

## Contexto Normativo

**Resolucion 0312 de 2019, Decreto 1072/2015 Art 2.2.4.6.6:**
El COPASST debe reunirse mensualmente y revisar el cumplimiento del Plan de Trabajo del SG-SST. La revision en la reunion de un mes corresponde a las actividades ejecutadas en el mes **anterior**, no al mes en curso.
