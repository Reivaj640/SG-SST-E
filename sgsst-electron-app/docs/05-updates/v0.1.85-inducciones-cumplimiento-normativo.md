# 📊 v0.1.85 - Feature: Tarjeta de Inducciones con Cumplimiento Normativo Real

**Fecha:** 20 de marzo de 2026  
**Tipo:** Feature / Mejora Crítica  
**Módulo afectado:** Recursos → Home (Dashboard)  
**Archivos modificados:** `main.js`, `modules/recursos/recursos-home.js`

---

## 📋 Resumen Ejecutivo

### Problema Anterior

La tarjeta de estadísticas de **Inducciones** en el dashboard del módulo Recursos mostraba información incompleta:

- ❌ **Solo mostraba histórico:** `X / Y` donde Y era el total de inducciones detectadas en Excel
- ❌ **No calculaba pendientes reales:** No había forma de saber cuántos trabajadores faltaban por capacitar
- ❌ **Porcentaje incorrecto:** 100% si todas las inducciones detectadas estaban completas (sin contexto normativo)
- ❌ **Sin referencia a la nómina:** No usaba el número real de trabajadores de la empresa

**Ejemplo del problema:**
```
Empresa: 50 trabajadores
Inducciones detectadas en Excel: 35
Inducciones completadas: 35

Widget anterior:
  Valor: "35 / 35"
  Mensaje: "✔ 100% Completado"

❌ PROBLEMA: Faltan 15 trabajadores por capacitar, pero el widget dice 100%
```

### Solución Implementada

Ahora la tarjeta usa el **número de trabajadores configurado en la empresa** como denominador:

- ✅ **Muestra cumplimiento real:** `X / Y` donde Y = total de trabajadores
- ✅ **Calcula pendientes:** `pendientes = empleados - completadas`
- ✅ **Porcentaje normativo:** `(completadas / empleados) * 100`
- ✅ **Alertas inteligentes:** 3 niveles basados en cumplimiento normativo

**Ejemplo con la solución:**
```
Empresa: 50 trabajadores (configurado en stats.employees)
Inducciones detectadas en Excel: 35
Inducciones completadas: 35

Widget nuevo:
  Valor: "35 / 50"
  Mensaje: "⚠ Refuerzo necesario (15 pendientes)"

✅ SOLUCIÓN: Muestra los 15 trabajadores faltantes y el 70% real de cumplimiento
```

### Impacto

| Métrica | Antes | Después | Mejora |
|---------|-------|---------|--------|
| **Precisión del dato** | Histórico (inducciones/inducciones) | Normativo (completadas/trabajadores) | ✅ +100% |
| **Pendientes visibles** | No mostraba | Muestra cantidad exacta | ✅ +100% |
| **Porcentaje útil** | 100% (siempre que hubiera datos) | Real según nómina | ✅ +100% |
| **Acción requerida** | Ninguna (falso positivo) | Alerta de refuerzo/crítico | ✅ +100% |

## 🔍 Análisis del Problema

### Arquitectura de Datos

**Fuente del número de trabajadores:**
```javascript
config.companyPaths[empresa].stats.employees
```

Este valor ya se usaba para:
- ✅ Determinar el **escenario normativo** (Resolución 0312 de 2019)
- ✅ Calcular obligaciones según número de trabajadores
- ✅ Definir si requiere Comité de Convivencia, COPASST, etc.

**Pero NO se usaba para:**
- ❌ Calcular cumplimiento de inducciones
- ❌ Mostrar trabajadores pendientes por capacitar

### Flujo de Datos Anterior

```
┌─────────────────────────────────────────────────────────────┐
│  Excel (ACT-FO-046)                                         │
│  Inducciones completadas: 35                                │
└────────────────────┬────────────────────────────────────────┘
                     │
                     ▼
┌─────────────────────────────────────────────────────────────┐
│  BACKEND (calculateInduccionesStats)                        │
│  totalInducciones = 35                                      │
│  completadas = 35                                           │
│  pendientes = 0  ❌ (no calculaba)                          │
│  porcentaje = 100%  ❌ (falso positivo)                     │
└────────────────────┬────────────────────────────────────────┘
                     │
                     ▼
┌─────────────────────────────────────────────────────────────┐
│  FRONTEND (createInductionWidget)                           │
│  Muestra: "35 / 35"                                         │
│  Mensaje: "✔ 100% Completado"  ❌ (engañoso)                │
└─────────────────────────────────────────────────────────────┘
```

### Por qué era un Problema Crítico

1. **Incumplimiento normativo oculto:**
   - La Resolución 0312 exige capacitar al **100% de los trabajadores**
   - El widget mostraba 100% aunque faltaran trabajadores por capacitar

2. **Falsa sensación de seguridad:**
   - El área de SST podía creer que estaba al día
   - En auditoría, se descubría que faltaban inducciones

3. **No permitía planificación:**
   - Sin saber cuántos trabajadores faltan, no se puede planear capacitaciones
   - Imposible calcular presupuesto para inducciones pendientes

## 🛠️ Cambios Implementados

### 1. Backend (`main.js`)

#### Función `calculateInduccionesStats()` (líneas ~7430-7545)

**Firma anterior:**
```javascript
async function calculateInduccionesStats(basePath)
```

**Nueva firma:**
```javascript
async function calculateInduccionesStats(basePath, companyName)
```

**Cambios principales:**

```javascript
// ========================================================================
// 1. LEER NÚMERO DE TRABAJADORES DESDE CONFIG
// ========================================================================
if (companyName) {
  try {
    const configData = await fsp.readFile(configPath, 'utf8').catch(() => '{}');
    const config = JSON.parse(configData);
    const employees = config.companyPaths?.[companyName]?.stats?.employees || 0;
    stats.totalTrabajadores = employees;
    sendLog(`[DEBUG] calculateInduccionesStats - ${companyName}: ${employees} trabajadores`, 'DEBUG');
  } catch (configError) {
    sendLog(`[WARN] Error leyendo config para ${companyName}: ${configError.message}`, 'WARN');
  }
}

// ... (código existente para leer Excel ACT-FO-046) ...

// ========================================================================
// 2. CALCULAR PENDIENTES Y PORCENTAJE REAL BASADO EN TRABAJADORES
// ========================================================================
// Calcular pendientes: trabajadores que NO han recibido inducción
stats.pendientes = Math.max(0, stats.totalTrabajadores - stats.completadas);

// Calcular porcentaje REAL: (completadas / totalTrabajadores) * 100
if (stats.totalTrabajadores > 0) {
    stats.porcentajeCompletado = Math.round((stats.completadas / stats.totalTrabajadores) * 100);
} else {
    // Fallback: si no hay empleados configurados, usar lógica antigua
    stats.porcentajeCompletado = stats.totalInducciones > 0 ? 100 : 0;
}
```

**Nueva estructura de retorno:**
```javascript
{
  totalTrabajadores: 50,      // ← NUEVO: Desde config.stats.employees
  totalInducciones: 35,       // Detectadas en Excel ACT-FO-046
  completadas: 35,            // Inducciones completadas (año actual)
  pendientes: 15,             // ← CAMBIA: employees - completadas
  porcentajeCompletado: 70,   // ← CAMBIA: (completadas / employees) * 100
  mensual: [0, 5, 10, ...]    // Tendencia mensual (sin cambios)
}
```

#### Función `createInductionWidget()` (líneas ~961-992)

**Código anterior:**
```javascript
createInductionWidget() {
    const stats = this.resourceStats?.inducciones || { 
        totalInducciones: 0, 
        completadas: 0, 
        pendientes: 0, 
        porcentajeCompletado: 0 
    };

    const title = 'Inducciones';
    const value = `${stats.completadas} / ${stats.totalInducciones}`;

    let desc = '';
    const porcentaje = stats.totalInducciones > 0 
        ? Math.round((stats.completadas / stats.totalInducciones) * 100) 
        : 0;

    if (porcentaje >= 80) {
        desc = `✔ ${porcentaje}% Completado`;
    } else if (porcentaje >= 50) {
        desc = `⚠ ${porcentaje}% Completado`;
    } else {
        desc = `❌ ${porcentaje}% Completado (${stats.pendientes} Pendientes)`;
    }

    // ... render
}
```

**Nuevo código:**
```javascript
createInductionWidget() {
    const stats = this.resourceStats?.inducciones || { 
        totalTrabajadores: 0, 
        totalInducciones: 0, 
        completadas: 0, 
        pendientes: 0, 
        porcentajeCompletado: 0 
    };

    // Usar totalTrabajadores como denominador (o fallback a totalInducciones si es 0)
    const totalTrabajadores = stats.totalTrabajadores || stats.totalInducciones;
    const completadas = stats.completadas;
    const pendientes = stats.pendientes || Math.max(0, totalTrabajadores - completadas);
    const porcentaje = stats.porcentajeCompletado || 0;

    const title = 'Inducciones';
    const value = `${completadas} / ${totalTrabajadores}`;

    let desc = '';
    
    // Manejar caso especial: no hay trabajadores configurados
    if (totalTrabajadores === 0) {
        desc = '⚠ Configure N° trabajadores en Ajustes';
    } else if (porcentaje >= 90) {
        desc = `✔ Cumplimiento óptimo (${pendientes} pendientes)`;
    } else if (porcentaje >= 50) {
        desc = `⚠ Refuerzo necesario (${pendientes} pendientes)`;
    } else {
        desc = `❌ Crítico: ${pendientes} trabajadores sin inducción`;
    }

    const w = document.createElement('div');
    w.className = 'widget';
    w.innerHTML = `
        <h4>${title}</h4>
        <div class="widget-value">${value}</div>
        <div class="widget-description">${desc}</div>
    `;
    return w;
}
```

**Cambios clave:**

| Cambio | Descripción | Beneficio |
|--------|-------------|-----------|
| **Denominador** | `totalTrabajadores` en lugar de `totalInducciones` | Muestra realidad normativa |
| **Fallback** | Si `totalTrabajadores = 0`, usa `totalInducciones` | Compatible con datos antiguos |
| **Mensaje de configuración** | `"⚠ Configure N° trabajadores en Ajustes"` | Guía al usuario |
| **Umbrales de alerta** | 90% (óptimo), 50% (refuerzo), <50% (crítico) | Alineado con auditoría SST |
| **Texto de alerta** | Más explícito: `"X trabajadores sin inducción"` | Claridad para la acción |

## 📝 Guía de Configuración para Usuarios

### Cómo Configurar el Número de Trabajadores

**Paso 1: Ir a Configuración**
- Click en el menú lateral: **"Configuración"**
- Seleccionar: **"Ajustes de Empresa"**

**Paso 2: Editar Empresa**
- Buscar la empresa en la lista
- Click en **"Editar"**

**Paso 3: Actualizar Número de Trabajadores**
- Campo: **"Número de trabajadores"** (o `stats.employees`)
- Ingresar el valor real de la nómina
- Ejemplo: `50`

**Paso 4: Guardar**
- Click en **"Guardar cambios"**
- Reiniciar la aplicación (opcional, para asegurar recarga)

**Paso 5: Verificar**
- Ir a: **Recursos** (dashboard)
- Verificar que la tarjeta de Inducciones muestra el nuevo valor
- Ejemplo: `"35 / 50"` en lugar de `"35 / 35"`

## 🎯 Lecciones Aprendidas

### Qué Funcionó

1. **Reutilizar datos existentes:** `stats.employees` ya estaba en el config, solo faltaba usarlo
2. **Fallback inteligente:** Compatible con empresas que no tienen `employees` configurado
3. **Mensajes de guía:** El widget indica al usuario qué hacer si falta configuración
4. **Logging detallado:** Facilita la depuración y validación

### Qué se Puede Mejorar

1. **Validación en UI:** Podría haber un indicador visual en "Ajustes de Empresa" si `employees = 0`
2. **Sincronización automática:** Podría leer la nómina desde el Excel de empleados (PI-FO-001)
3. **Histórico de cumplimiento:** Guardar el % de cumplimiento por mes para tendencias

### Recomendaciones Futuras

1. **Auto-detectar empleados:** Leer el total de empleados desde la nómina (si existe)
2. **Alertas proactivas:** Notificar cuando el cumplimiento baje del 90%
3. **Plan de acción:** Sugerir capacitaciones mensuales para alcanzar 100%
