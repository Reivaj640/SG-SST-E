**Fecha:** 26 de Marzo 2026  
**Tipo:** Mejora de UX + Nueva Funcionalidad

## 📋 Resumen

Esta actualización introduce:
1. **Widget de Actas COPASST parametrizado** (similar a Afiliación SSSI)
2. **Alertas de Comité de Convivencia mejoradas** (2 alertas: constitución + reuniones)
3. **Scrollbars personalizados grises** (armonizan con diseño de la app)
4. **Scroll funcional en tamaño mínimo** (1024x650)

### 2. Alertas de Comités Mejoradas

#### COPASST - 2 Alertas

**Alerta 1: Constitución/Período**
```javascript
// Período vigente (2024-2026)
INFO: COPASST: Constitución al día (Período 2024-2026)
Descripción: Última elección: 2024. Próxima renovación: Diciembre 2026.

// Período vencido (2022-2024)
CRITICAL: COPASST: Período vencido (2022-2024)
Descripción: Última elección: 2022. Período máximo: 2 años. 
             Próxima elección requerida: Antes de diciembre 2024.
```

**Alerta 2: Reuniones Mensuales**
```javascript
// Faltan reuniones
CRITICAL: COPASST: Sin reunión desde Febrero 2026
Descripción: Última acta registrada: Febrero 2026. 
             Mes actual: Marzo 2026. 
             Requisito: Reuniones mensuales. 
             Meses sin acta: Marzo
```

#### Comité de Convivencia - 2 Alertas

**Misma lógica que COPASST:**
- Alerta de período (vigente/vencido/por vencer)
- Alerta de reuniones mensuales faltantes

### 4. Scroll en Tamaño Mínimo

**Problema:**
- Ventana en tamaño mínimo (1024x650)
- Scrollbars no aparecían en dashboard
- Contenido se cortaba sin opción de scroll

**Solución:**
```css
/* Forzar altura máxima para activar scroll */
[data-module-list],
#tasks-container {
  max-height: calc(100vh - 200px);
  overflow-y: auto !important;
  min-height: 0 !important;
}
```

**Cálculo:**
```
Ventana mínima:     650px
- Header            70px
- KPIs row          80px
- Padding/Gaps      50px
───────────────────────
Altura restante:   450px  ← Para módulos y tareas
```

// Línea ~1230
createCopasstWidget() {
  const stats = this.resourceStats?.copasst || { 
    totalActas: 0,
    actaMesEnCurso: false,
    ultimoMesRegistrado: null,
    actasAnio: 0,
    estado: 'ok',
    alertas: []
  };

  const currentYear = new Date().getFullYear();
  const currentMonthName = monthNames[currentMonth];

  // Determinar color y estado
  const alDia = stats.actaMesEnCurso;
  let colorVar = alDia ? 'var(--k-success)' : 'var(--k-danger)';
  let colorClass = alDia ? 'bg-success' : 'bg-danger';
  let statusText = alDia ? 'Al día' : 'Pendiente';

  const w = document.createElement('div');
  w.className = 'widget k-budget-card';

  w.innerHTML = `
    <div class="kb-header">
      <span class="kb-title">Actas COPASST ${currentYear}</span>
      <span class="kb-badge ${colorClass}">${statusText}</span>
    </div>

    <div class="kb-amount">${stats.totalActas} acta${stats.totalActas !== 1 ? 's' : ''}</div>

    <div class="kb-footer">
      <div>
        <div class="kb-label">Mes actual</div>
        <div class="kb-value" style="color: ${colorVar}">${currentMonthName}</div>
      </div>
      <div style="text-align: right;">
        <div class="kb-label">Último registro</div>
        <div class="kb-value">${stats.ultimoMesRegistrado || 'N/A'}</div>
      </div>
    </div>
  `;

  return w;
}

## ⚠️ Breaking Changes

### Widget de EPPs eliminado
- **Antes:** `createEPPWidget()` mostraba EPPs entregados
- **Ahora:** `createCopasstWidget()` muestra Actas COPASST
- **Razón:** Priorizar métricas de comités sobre EPPs

### Cambio de estructura de datos
- **Antes:** `calculateCopasstStats()` retornaba `{ totalActas, actasAnio, ultimaReunion, mesesFaltantes }`
- **Ahora:** Retorna `{ totalActas, actaMesEnCurso, ultimoMesRegistrado, actasAnio, estado, alertas }`
- **Razón:** Estandarizar con patrón de Afiliación SSSI
