## 📦 Lo que incluye

### 1. Google OAuth + Gmail API

- **Google Cloud project** "KAIR Calendar Sync" configurado
- **`shared/google-auth.js`** (276 líneas): Flow OAuth2 con PKCE
  - Scopes: `gmail.readonly` + `gmail.send` + `gmail.compose`
  - Token refresh automático (no expiration check, refresh permanente)
- **`shared/google-tokens.js`** (86 líneas): `hasValidTokens()` chequea `refresh_token`
- **`shared/google-gmail.js`** (485 líneas): Wrapper `gmail.users.*`
  - `listInbox`, `getMessage`, `markRead`, `sendMessage` (raw MIME + base64url)
  - `listLabels`, `downloadAttachment`, `archiveThread`
- **Dependencia nueva**: `googleapis ^173.0.0`

### 2. SQLite Cache (Fase 0)

- **5 tablas** en `kair.db`: `connections`, `threads`, `messages`, `labels`, `attachments`
- **`main/email-schema-sql.js`** (136 líneas): Schema completo + migraciones
- **`main/email-db.js`** (422 líneas): CRUD con lazy `db()` (singleton pattern)
- **`main/email-sync.js`** (414 líneas): `syncInbox()` con TRUNCATE-then-INSERT, RFC 2822 parsers
- **9 IPC handlers nuevos**: `email-cache:sync-inbox`, `:get-threads`, `:get-thread`, `:get-stats`, `:get-labels`, `:get-attachments`

**Bugs fixed en Fase 0:**
- `references` reserved word (renamed a `references_header`)
- `db.prepare is not a function` (lazy `db()` pattern)
- Fake headers pattern (remover headers inventados por Gmail API)
- Stale threads (TRUNCATE-then-INSERT)
- Empty body (lazy load on demand)

### 3. Gmail-look UI (Fase 1.A-D)

**Fase 1.A — Avatares y dot de no-leído:**
- Avatares 40x40 circulares con color derivado del email (`stringHashColor`)
- Dot azul reemplaza el checkbox cuando el correo no está leído
- Hover actions (archivar, marcar leído, eliminar) con gradient fade
- Body limpio: detecta/remueve headers MIME duplicados, linkify URLs

**Fase 1.B — Compose/Reply/Forward + Enviados:**
- Modal compose con pre-fill automático según modo (reply, replyAll, forward, new)
- Soporte para carpeta "Enviados" (`state.mailFolder`)
- Pre-load SENT en background después de 2s
- Race condition fix: verificar folder match antes de actualizar state.mails

**Fase 1.C — Thread grouping:**
- `loadMailBodyFromCache` ahora trae TODOS los mensajes del hilo (no solo el último)
- `renderMailDetail` apila los mensajes con avatar + sender + body
- Separator border-bottom entre mensajes
- Compatibilidad con mensajes únicos (1 msg = render original)

**Fase 1.D — Búsqueda en tiempo real:**
- `state.searchQuery` con `searchInput`
- Icon + placeholder + clear button (X) + ESC
- **CSS-only filtering** con data-attributes (preserva foco del input)

### 5. 5 Features Future

- **Labels reales**: `listLabels()` trae los labels de Gmail con colores, chips en UI (solo USER + STARRED + IMPORTANT)
- **Search operators**: `from:`, `to:`, `subject:`, `has:attachment`, `after:`, `before:` + texto libre
- **Sync bidireccional**: `markMessageRead` y `archiveThread` reflejan cambios en Gmail real
- **Firma al enviar**: `localStorage["kair.emailSignature"]`, separador estándar `-- `
- **Adjuntos reales**: `downloadAttachment` con base64url → Blob → download nativo

### 6. 6 Afinamientos Visuales

- Subject 1.4rem → 1.5rem, letter-spacing -0.018em
- Detail avatar 48px → 52px
- Filter active con bg primary + shadow
- Empty state con SVG icon
- Row padding 10px 16px, gap 12px
- Toolbar detail padding 8px 16px, bg #fafbfc

### 7. Thread Grouping Gmail-style

- Solo último mensaje expandido, resto colapsado
- Collapsed: avatar 32x32 + name + snippet 1-line ellipsis
- Quoted text colapsable con `<details>` y summary "··· N líneas citadas"
- Compose modal Gmail-style con titlebar oscuro, toolbar inferior, atajos ESC/Ctrl+Enter

### 8. Features Post-BEM

- **Adjuntos reales**: downloadMailAttachment async, formatAttachmentSize, attachmentIcon
- **Editor de firma**: botón "Firma" en header + .kair-signature-modal con live preview
- **Badge "N mensajes"** en la lista cuando thread > 1 mensaje
- **Auto-refresh cada 5 minutos** (setInterval, pause en visibilitychange, stop en navigateBack)
- **Operadores visuales con chips removibles** (getActiveOperators, removeOperatorFromQuery, updateOperatorChips en vivo)
- **Quote del reply como bloque HTML arriba del textarea** (NO texto plano)

### 9. 4 Fixes Visuales Gmail-style

Basados en comparación visual con Gmail:

1. **Bug: "De:/Enviado:/Para:/Asunto:" en body** — regex que matchea headers MIME línea por línea en cualquier parte
2. **Email cortado feo** — `overflow-wrap: anywhere` (no `text-overflow: ellipsis` con `nowrap`)
3. **Formato "hace X horas"** — `formatRelativeTime` (hace X min/horas/días para < 7 días)
4. **Label "Recibidos"** — chip removable al lado del subject (.kair-mail-detail__folder-label)

### 10. Integración con App Principal

- **`index.html`**: Botón "Bandeja Integrada" con badge de alertas (KAirAlerts replicado)
- **`renderer.js`**: Iframe con cache-bust dinámico (v=576 → 613), postMessage para toggle/close
- **`config-viewer.html`**: Sección Gmail completa con switch iOS + email conectado
- **3 formas de salir**: Toggle, FAB "← Volver", ESC
- **Coexistencia**: K+AIR Calendar sigue funcionando independiente
