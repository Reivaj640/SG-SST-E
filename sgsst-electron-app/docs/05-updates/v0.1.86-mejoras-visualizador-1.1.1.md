## 🎯 Funcionalidades Detalladas

### 1. 📤 Arrastrar y Soltar Archivos (Drag & Drop)

**Descripción:** Permite subir archivos arrastrándolos desde el explorador de archivos del sistema directamente sobre una carpeta en el visualizador.

**Comportamiento:**
- ✅ Overlay azul aparece **solo sobre la carpeta** donde se arrastra
- ✅ Ícono animado (bounce) indica zona de drop
- ✅ Borde dashed azul en la carpeta destino
- ✅ Múltiples archivos se procesan en paralelo
- ✅ Notificación toast por cada archivo subido

**Archivos soportados:**
- PDF (`.pdf`)
- Excel (`.xls`, `.xlsx`)
- Word (`.doc`, `.docx`)
- Texto (`.txt`)
- Imágenes (`.jpg`, `.jpeg`, `.png`)

**Validaciones:**
- ✅ Tamaño máximo: **10MB**
- ✅ Caracteres inválidos en nombre: `<>:"/\|?*`
- ✅ Ruta de destino debe existir
- ✅ Sobrescritura automática (con log de advertencia)

**UX:**
```
┌─────────────────────────────────┐
│  📁 Carpeta Destino             │
│  ┌─────────────────────────┐   │
│  │  ☁️ Suelta aquí         │   │
│  │  Se guardará en esta    │   │
│  │  carpeta                │   │
│  └─────────────────────────┘   │
└─────────────────────────────────┘
```

### 3. 🔗 Abrir con Aplicación Predeterminada

**Descripción:** Abre el archivo seleccionado con la aplicación predeterminada del sistema operativo.

**Implementación:**
- Usa `shell.openPath()` de Electron
- Respeta asociaciones de archivos del sistema
- Funciona para todos los tipos de archivos

**Ejemplos:**
| Tipo de Archivo | Aplicación Predeterminada |
|-----------------|--------------------------|
| `.pdf` | Adobe Reader, Edge, Chrome |
| `.xlsx` | Microsoft Excel |
| `.docx` | Microsoft Word |
| `.jpg` | Visor de Fotos de Windows |

**Manejo de errores:**
- ✅ Archivo no existe → Toast de error
- ✅ Sin aplicación predeterminada → Error del sistema
- ✅ Permiso denegado → Toast de error

### 4. 🗑️ Eliminar Archivos con Confirmación

**Descripción:** Elimina archivos del sistema de archivos con confirmación mediante modal moderno.

#### Modal de Confirmación K+AIR

**Diseño:**
```
┌──────────────────────────────────────────────────┐
│ ⚠️  Confirmar eliminación                        │
├──────────────────────────────────────────────────┤
│                                                  │
│ ¿Está seguro de eliminar "archivo.pdf"?          │
│                                                  │
│ ╭────────────────────────────────────────────╮  │
│ │ ℹ️  Esta acción no se puede deshacer.      │  │
│ ╰────────────────────────────────────────────╯  │
│                                                  │
│                    [Cancelar]  [🗑️ Eliminar]    │
└──────────────────────────────────────────────────┘
```

**Características:**
- ✅ Animación slide-in desde arriba
- ✅ Ícono de advertencia amarillo
- ✅ Nombre del archivo en negrita
- ✅ Mensaje de advertencia en amarillo
- ✅ Botón "Cancelar" (ghost, gris)
- ✅ Botón "Eliminar" (danger, rojo)
- ✅ Cierra con clic fuera
- ✅ Cierra con tecla Escape
- ✅ Focus management (Cancel por defecto)

#### Manejo de Errores Específico

**Errores de Windows manejados:**

| Código | Causa | Mensaje al Usuario | Tipo Toast |
|--------|-------|-------------------|------------|
| **EPERM** | Archivo en uso | "El archivo está abierto en otra aplicación. Ciérralo e intenta nuevamente." | ⚠️ Warning (6s) |
| **ENOENT** | Archivo no existe | "El archivo no existe. Puede que ya haya sido eliminado." | ℹ️ Info (3s) |
| **EACCES** | Sin permisos | "No tienes permisos para eliminar este archivo." | ❌ Error (3s) |
| **Otros** | Varios | Mensaje de error original | ❌ Error (3s) |

**Flujo de eliminación:**
```
1. Clic derecho en archivo
   ↓
2. Click en "🗑️ Eliminar archivo"
   ↓
3. Modal de confirmación aparece
   ↓
4. Usuario confirma (click en "Eliminar")
   ↓
5. Backend intenta eliminar
   ↓
6. ¿Éxito?
   ├── ✅ Sí → Toast verde + recargar lista
   └── ❌ No → Toast específica según error
```

## 🔧 Cambios Técnicos Detallados

### 1. Drag & Drop por Carpeta

**Implementación:**
```javascript
function setupFolderDragAndDrop(folderElement, folderPath) {
    // Crear overlay dinámico
    const overlay = document.createElement('div');
    overlay.className = 'drag-drop-overlay';
    
    // Configurar eventos
    folderElement.addEventListener('dragenter', showOverlay);
    folderElement.addEventListener('dragleave', hideOverlay);
    folderElement.addEventListener('drop', handleDrop);
}
```

**Características únicas:**
- Overlay se genera **por cada carpeta** en `renderFolders()`
- No hay overlay global en todo el sidebar
- Tracking individual por carpeta con `dragCounter`

### 3. Confirm Modal con Callback

**Patrón de diseño:**
```javascript
let confirmCallback = null;

function showConfirmModal(fileName, callback) {
    confirmCallback = callback;
    modal.style.display = 'flex';
}

function acceptConfirm() {
    if (confirmCallback) {
        confirmCallback();
    }
    hideConfirmModal();
}
```

**Ventajas:**
- Reutilizable para diferentes operaciones
- Callback asíncrono soportado
- Sin acoplamiento con la lógica de negocio

### 4. Toast Notifications System

**Función central:**
```javascript
function showToast(message, type = 'info', duration = 3000) {
    const toast = document.createElement('div');
    toast.className = `k-toast ${type}`;
    toast.innerHTML = `
        <i class="fas ${icons[type]} k-toast-icon"></i>
        <span class="k-toast-message">${message}</span>
    `;
    
    container.appendChild(toast);
    
    setTimeout(() => {
        toast.classList.add('closing');
        setTimeout(() => toast.remove(), 300);
    }, duration);
}
```

**Características:**
- Contenedor único (`k-toast-container`)
- Múltiples toasts visibles simultáneamente
- Animaciones CSS (slideInRight, slideOutRight)
- Auto-limpieza de elementos DOM

## 📝 Lecciones Aprendidas

### Qué Funcionó Bien

1. **Drag & Drop por carpeta** - Mejor UX que overlay global
2. **Modal de confirmación** - Más profesional que `confirm()` nativo
3. **Manejo específico de errores** - Usuarios entienden mejor el problema
4. **Toast notifications** - Feedback visual consistente

### Desafíos Encontrados

1. **EPERM en Windows** - Archivos en uso no se pueden eliminar
   - **Solución:** Mensaje claro al usuario + logging detallado

2. **Posicionamiento de menú** - Se salía de pantalla en monitores pequeños
   - **Solución:** Ajuste dinámico basado en `getBoundingClientRect()`

3. **Comunicación iframe ↔ parent** - Handlers faltantes en renderer.js
   - **Solución:** Agregar casos en switch de renderer.js y logic.js

### Recomendaciones Futuras

1. **Confirmación para múltiples archivos** - Si se seleccionan varios, confirmar en lote
2. **Papelera de reciclaje** - Mover a papelera en lugar de eliminar permanentemente
3. **Deshacer eliminación** - Breve ventana para recuperar archivo eliminado
4. **Progreso de subida** - Barra de progreso para archivos grandes (>5MB)

## 📞 Soporte

Si encuentras problemas relacionados con esta actualización:

1. **Verificar consola (F12)** - Buscar logs con prefijo:
   - `[Drag&Drop]` - Problemas de arrastrar y soltar
   - `[ContextMenu]` - Problemas de menú contextual
   - `[ConfirmModal]` - Problemas de confirmación
   - `[Toast]` - Problemas de notificaciones

2. **Validar permisos** - Asegurar que la aplicación tiene permisos de escritura en la carpeta

3. **Cerrar archivos en uso** - Para eliminar, el archivo no debe estar abierto en otra aplicación

4. **Reportar bug** - Incluir:
   - Logs completos de consola
   - Tipo de archivo
   - Sistema operativo
   - Pasos para reproducir
